How to file a request

  1. Find the model you want printed (Printables, MakerWorld, Thingiverse, anywhere with a link).
  2. Choose New request and paste the link. The title and a picture are filled in when the site allows it; if not, type a title yourself.
  3. Say how many you need, what it should be made of, and whether there is a deadline, then file it.
  4. Check back on the request page: questions and progress show up there.

Bookmarklet

Drag this button to your bookmarks bar. On any model page, click it to open a new request with the link already filled in. You stay signed in, so there is nothing else to set up.

File a print request

Drag it rather than clicking it here. It opens {{.BaseURL}}/requests/new?url=… in a new tab.

On a phone

Bookmarklets are awkward on phones. Instead, copy the link from the model page (share, then copy link), open New request and paste it into the link field.
